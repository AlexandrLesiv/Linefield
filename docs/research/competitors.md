# Competitor reference catalog

Updated 2026-10-16. Owner-selected primary references: Concepts, ProDrafts and Apple Freeform for
macOS. Concepts remains the directional sketching reference. Other entries are research candidates,
not adopted features or a parity roadmap.
Descriptions below are documented vendor/store claims, not hands-on observations or benchmarks.
Exact version, platform, subscription limits and behavior must be checked in the assigned feature study.

## Drawing and handwritten infinite-canvas notes

| Reference | Documented relevance / evidence | Suggested research focus (our recommendation) |
| --- | --- | --- |
| Concepts | Owner-selected editable vector sketching reference; retain existing S00C direction | Stroke editing, tool discoverability, canvas navigation and desktop/pen interactions |
| [ProDrafts / Prodrafts](https://apps.apple.com/us/app/prodrafts-infinite-notes/id1545810067) | Developer listing describes handwritten infinite canvas, paged notes, PDF annotation and mind maps | Primary added reference: pen-to-navigation transitions, tool presentation, library/document organization; inspect platform differences rather than infer native Mac behavior from listing availability |
| [Defter Notes](https://defternotes.com/handbook/getting-started) | Official handbook describes infinite-space handwriting designed for iPad and Pencil | Spatial arrangement and touch/Pencil interaction; useful tablet reference rather than proof of desktop behavior |
| [Notein](https://help.notein.ai/category/getting-started/standard-note-vs-infinite-canvas?lang=en) | Official documentation distinguishes standard notes from a continuous canvas; [vendor site](https://www.notein.ai/) identifies Android handwriting focus | Android stylus/touch modes, canvas versus page navigation and tool discoverability |
| [Apple Freeform](https://support.apple.com/en-gb/guide/iphone/iphb86e84e2b/ios) | Apple's guide describes a boundless board for content | Owner-selected primary macOS competitor: research native controls, app menus, keyboard/trackpad interaction, board navigation and organization. Verify macOS separately; this iPhone source does not establish Mac behavior |

## Adjacent spatial-note and knowledge-board references

These help with organization and navigation; do not assume they offer Concepts-like editable ink.

| Reference | Documented relevance / evidence | Suggested research focus |
| --- | --- | --- |
| [Obsidian Canvas](https://obsidian.md/canvas) | Infinite visual arrangement of notes and embedded media | Connections, grouping and navigating larger workspaces; built-in Canvas is not evidence of freehand drawing support |
| [Scrintal](https://scrintal.com/) | Canvas-based notes/research and linked content | Moving between spatial overview and focused note reading/editing |
| [Heptabase](https://heptabase.com/) | Whiteboards and cards for organizing knowledge | Card/board navigation, overview and information organization; do not infer unlimited extent or ink behavior |
| [Allume, formerly Muse](https://allume.com/) | museapp.com redirects to Allume; vendor describes a mixed-content canvas and explicitly excludes endless canvas zooming | Adjacent reference for uncluttered spatial work and gesture discoverability, not an unbounded-zoom drawing competitor |

## Selecting a bounded study

The initial S00C comparison covers Concepts, ProDrafts and Freeform on macOS; Freeform is required,
not an optional third candidate. Keep each study bounded to its feature questions. Later studies
can select Defter Notes for iPad handwriting or Notein for Android input. Use card-based references when a future approved
organization feature warrants them. Catalog inclusion does not authorize text/PDF/mind-map/layer/sync
features, extra platforms, new inputs or feature imitation.

Follow [research workflow](README.md). Give owner, UX and UI the same sourced recommendations; UX
plans relevant inputs using [inventory](../input/inventory.md) and submits the feature proposal with
identified Figma for owner approval. No up-front global shortcut decisions. Native engineer checks
feasibility. Record documented versus observed behavior and unknowns, including native/compatible
platform delivery; don't use app-store reviews as measured latency or correctness evidence.

This catalog is a public-source shortlist, not completion of S00C's feature workflow analysis.
No apps installed, accounts used, paid features accessed, designs copied or app behavior tested.
