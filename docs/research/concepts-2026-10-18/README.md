# Research report availability

This directory versions the written research, report source and analysis helpers. Its `assets/`
directory contains private local captures, including unrelated drawings; it is intentionally
ignored and **not included in the public repository**. HTML media links therefore cannot all
render from a public clone. Missing public media is not evidence of a reproduced browser study.

The original local assets are preserved in the working checkout and the local bootstrap recovery
copy. Do not force-add, upload or delete them as part of publication or diagram conversion.
See observations.md/report.md for scope and evidence limitations; externally accessible official
source links remain separate from these private captures.
