# M04 certified pan-region reuse

The lead adopts this bounded integration under the owner’s renewed M04 authorization, subject
to independent contract review before implementation. Existing arithmetic and integer-quad
proofs do not establish production parity. Enable reuse only after the integrated correctness,
lifetime and useful-performance checkpoint below; preserve the complete reconstruction path.

## Outcome and ownership

Copy the certified same-prefix overlap from existing B into existing S, then reconstruct at most
four disjoint exposed rectangles. Rust owns canonical editing/camera state, captured raster phase,
precision, culling and typed admission. The host owns disposable image copies, scissoring, GPU
resources and scheduling. No archive, atlas, extra texture, dirty-region ABI or worker topology.

Walk the captured prefix once. Prepare/place each page once, reject pages outside all dirty
rectangles, bind/upload each surviving page once and issue at most four bounded scissored draws.
Composite each group only into those disjoint rectangles. Charge each issued draw to existing
budgets; retain loans across rectangle yields without holding a GPU slot. This can reduce GPU
work but still traverses/prepares the prefix; it does not promise removal of cold preparation.

## Exact accepted displacement

Use the existing checked22-word dyadic magnitude to prove whether
`savedIntegerOffset + (acceptedCurrentCSS − acceptedStartCSS) × backing` is exactly integral.
Decode finite input bits and multiply the53-bit backing mantissa without rounding the difference
first. Only a zero exact remainder permits an integer result. Overflow, unsupported range or
uncertainty is a categorized optional miss, never an accepted fractional pan or failed user pan.
Keep signed offset components within±16384. No dynamic bigint, epsilon, f32 comparison, rounded
canonical coordinates or additional per-event allocation.

Fractional updates render canonically and retain the pregesture anchor privately; later integral updates in that same gesture may recover. Range or certificate failure is sticky until End. Regional difference first checks the i128 region delta within the existing relative bound, then encloses `delta * 65536 + localA - localB` in that same operation order. - Per descriptor, additionally enclose the actual canonical and anchor translation evaluation from that descriptor's regional origin. Certify the same residual bound for that page and charge its additional source-dependent f64 enclosure width. The anchor-placement GPU arithmetic check uses the enlarged envelope: backing extent plus absolute offset, capsule radius and integer-quad expansion. Add rho and the extra integer-route arithmetic inside the existing 0.07 px allowance. Do not relax coefficient/translation/curve/packing budgets. - Visibility/preparation coverage remains canonical and expands outward for rho transformed through the inverse basis in addition to existing support/AA padding. ### Fixed source-B recipe certificate

Accumulate a fixed summary while B is produced: eligible flag, requested detail, shader/recipe generation and raster capture identity, plus categorized failure bits/counts. There is no page manifest, extra reader, admission prescan or unbounded pin.

Every contributing page carries immutable internal provenance from issuance through streaming/retention/borrowing: ordinary completed source chunk, exact requested detail, unclipped input, stable source-local partition/origin/packing and the same raster phase. Existing `Entry.detail` and token/clip facts are sufficient inputs, but token absence alone must not manufacture eligibility for a streamed page; attach the provenance when the actual preparation input is known. Finer or clipped/unknown pages remain usable in normal rendering but clear the B certificate. Do not disable retained-finer reuse globally.

Preserve the certificate across same-view seed only when inherited B and appended pages share the exact recipe. Any unknown live/tail/display fold clears it. When an already-required full reconstruction follows a provenance miss, use a bounded exact-detail/unclipped preference for certifiable compact chunks; do not start an extra idle rebuild. Broad/clipped sources remain honest misses. This should enable the next ordinary stopped pan rather than create a fixture-only cache.

Folding canonical live/tail coverage into an anchored base clears copy eligibility by default;
neither logical prefix equality nor a subpixel residual proves an identical raster recipe.
No new live/tail fallback ABI is introduced. Only anchored completed Prefix placement may return
anchorMiss; canonical current/live/tail keep their existing numerical/error policy.

Actual browser evidence must compare worker/fallback and evicted/regenerated page data, origins, partition and placement for identical immutable chunk/revision/detail. Equal logical source IDs are insufficient. Include a real B built through ordinary drawing and same-view seeding, not an injected certified bitmap. Newly exposed chunks use the same deterministic recipe even though they were absent from B.

Use the existing source receipt lease; borrow it before issuing copy and retain it until every copy/reconstruction reader and cleanup operation completes. The copy serial participates in validation even if no dirty geometry is visible.

Late placement/provenance failure after copying or drawing invalidates the entire unacknowledged candidate. Drain its readers, retire its resources and receipt, and permit at most one canonical full retry for that candidate/request. Never mix per-page canonical fallback into anchored pixels. If the request is no longer current, discard it rather than rebuild an obsolete target. Keep the previous valid display and immediate next-pen admission; cleanup alone cannot acknowledge the target or block input. Context loss follows existing generation/recovery, not a new recovery path.

mapping or session creates a different request. A failed canonical retry uses the existing typed
render failure/recovery path. Distinguish pan-copy from same-view successor seeding: pan-copy walks
the entire captured prefix, never uses the successor seed's after-through frontier.

Use existing bounded aggregate diagnostics for attempts, validated copies, copied/dirty pixel

## One bounded acceptance run, then application cost

Use the existing accepted-offset matrix and integer-quad baselines; add integrated-only cases. Positives: ordinary first/second stopped pan at 5%/100%, 0°/15°/90°/180°, DPR1/2/odd backing, far-region carry/borrow. Negatives: half pixel and 1±2^-30, offsets 16383/16384/16385, fractional→integer within gesture, End/Cancel, basis/metrics/session replacement, Undo/rebranch. Count integral eligible denominators and each conservative miss.

Pixels: exact copy+dirty versus anchored full reconstruction for actual B provenance, normal/packed targets, retained exact/finer/clipped and evicted/streamed geometry, overlapping translucent groups, dirty boundaries. Canonical-reference comparison retains existing geometry/AA tolerance. Unknown/finer/clipped paths must take complete fallback visibly, not a fake positive cache hit.

Lifecycle: issue copy plus an early page then fail a later certificate; hold two fences/eight receipts; empty dirty geometry; Cancel and new Begin while cleanup is pending. No partial acknowledgement, stale publication, packed-alpha damage or premature lease release. Fresh drawing remains usable.

Cover anchored B with canonical active L/F/T, stroke End/Cancel, folding and the next completed-B
eligibility. Compare the subsequent anchored Prefix against the canonical reference within the
existing geometry/AA budgets; mixed-plane testing does not grant a new tolerance.

After these cases and static/build/source review, run the existing full application pan/continue profile once per frozen control/candidate/control, with the previously proposed single additional existing panAndContinue call to separate first/second stopped pan. Record copied pixels, actual skipped draws/compositions, dirty area, remaining preparation, receipt acknowledgement and next-input latency. Require useful reduction in total work/elapsed acknowledgement; a copy counter is not success. Preserve all original unresolved performance flags. No archive until this path proves useful.

Keep first and second pan phases separate by ordinal, including the existing drawing and Undo
between them. On the admitted warm-pan lane require an exact End-to-ack improvement greater than
15% and2ms against both controls, reduced actual rendering work and no new adverse endpoints or
resource violations. Report first-miss overhead separately; never average it away or manufacture
a second-pan hit by removing intervening edits. Preserve existing absolute limits. The existing
interior-artwork timing scene is an empty-dirty positive, not evidence for newly revealed ink;
the integrated pixel cases must cover strokes crossing exposed boundaries.


Stop on a fractional false hit, seam, missing contributor, ownership/cap failure, or collapsed
ordinary integral eligibility. Do not widen precision or remove rotated/5% cases to obtain a pass.
A failed optional certificate selects full reconstruction, not failed user input.
