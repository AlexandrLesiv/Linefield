Decision 13 acceptance: extend S04 vector cache/culling evidence to completed editing/autosave
workloads. Verify memory bounds, cold/warm/evicted parity and invalidation across transforms,
Undo/Redo, zoom/display changes. Raster tiles require a separate measured proposal and owner review,
not an unreviewed optimization when a budget fails.

Decision 41 adds injected internal-failure acceptance: containable failures disable affected
session mutations, cannot autosave tainted state, reject late completions and allow validated
saved-content recovery without compromising unaffected functions. Assert redacted correlated
failure records and safe behavior with a failing diagnostic sink. Test independent process
crash/relaunch paths without claiming all faults are catchable. Verify in-flight write races
against reviewed S02 policy; native recovery UI still needs identified design and actual-host E2E.

Decision 65 adds JSON Lines diagnostics acceptance: validate framing/event schema/correlation,
allowlist redaction, oversized event rejection, truncated final record handling, rotation/retention,
queue saturation, disk/permission failure and shutdown/late completion. Verify editing remains
correct with failed sinks, bounded drops/failure counters and no recursive logging loop. Measure
runtime overhead separately; log presence alone is not proof every action survived a crash.

Decision 66 adds retention acceptance at seven-day and 20 MiB total logical-byte boundaries,
including active/rotated accounting and oldest-first removal. Exercise restart, clock changes,
cleanup/permission failure, oversized records and bounded sink degradation. Verify drawings,
recovery copies, test artifacts and unrelated files survive untouched. No editing failure/stall
or unbounded storage growth; do not claim runtime tests or cleanup while app is closed.

Decisions 100/101 add storage priority/fairness and sliced main-thread completion evidence. Exercise
preview backlog, sustained saves and completion bursts; measure input delay and eventual progress.
Count/time budgets do not preempt an active transaction or a single oversized handler. Require
bounded work, preserved result order and no lost completion. Decision 102 adds bounded export-
queue count/bytes/cancellation/destination-race acceptance after concrete contract approval.

Decisions 110-114: verify screenshot baselines at every suitable flow step with justified gaps,
semantic/AX checks and reviewed host tolerances. Normal native captures are screenshots/logs;
video is targeted, never an unaccounted benchmark overhead. Gate performance on reviewed absolute
and same-host relative thresholds with raw release evidence/repetitions/noise handling. Run longer
generated/fuzz campaigns at milestones; short bounded seeded campaigns belong to relevant background
commit checks. Test artifact pruning/pins/unresolved failures/capacity saturation safely in disposable
roots. Exact quotas remain reviewed; no protected evidence deletion or threshold/golden weakening.
