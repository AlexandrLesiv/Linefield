S00D Navigation and motion design

interruptible/reduced-motion transitions are implemented and verified under P05-G01/P05-D01.

P05-D01; durable route/identity lifetime and safe deep-link contracts still require review.
- Shared guard/typed effect boundary; pending/accepted navigation, stale requests and failures.
- Motion inventory, native/custom mappings, timing/interrupt/focus and reduced-motion behavior.

of identified foundations/screens/motion before UI implementation.
- Scenario mapping, remaining choices and concrete S02 inputs. No route framework selected silently.

Read [navigation](../docs/navigation.md), [motion](../docs/design/motion.md) and
[scenarios](../docs/testing/navigation-motion.md). Extend existing CT/INV/SU packets rather than
inventing a new binary protocol or shared cross-platform UI/router framework.

Completion: owner reviews scope and exact designs; technical contracts reviewed through S02.

associated domains, accounts and native/durable implementation remain unapproved. Existing
