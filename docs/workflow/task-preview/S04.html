Selected pen and artwork behavior

Follow decision 16 and the reviewed CT-02/S02 geometry contract: solid round pen, pressure-to-width
only, constant-width fallback, tilt ignored, retained width/color controls, fixed light artwork
background and system-themed chrome. No brush library or adjustable stabilization controls.
Extend DRAW-001/core fixtures to cover pressure presence/absence, stable opacity, ignored tilt,
transient predictions and unchanged artwork colors across UI theme changes. Record actual
Cintiq verification separately from synthetic fixtures. Decision 34 selects linear pressure
response and maximum-untransformed-width semantics. Decision 35 selects no movement filtering;
minimum/contact and precise geometry rules still require review before implementation. Map evidence to SU-03/SU-04 and applicable input invariants.

Decision 35 extends DRAW-001/core geometry fixtures with actual-path/endpoint/corner fidelity,
round joins/caps and duplicate/degenerate samples, without movement filtering. Antialiasing is
separate. Record real Cintiq jitter/feel as evidence, not an assumed pass. Persistence and PNG
parity are tested in their later task integrations; predictions remain transient.

Decision 47 extends DRAW-001: draw one stroke, change approved pen color/width through native
controls and draw another; the first retains its properties and the second uses the new settings.
Shared Rust validation/semantics remain authoritative. Test actual versus absent pressure with
per-stroke base width and the reviewed active-stroke settings contract. Shared style tables and
brush presets are not scope. Later S05/S06/S07E verify history, persistence and export parity.

Decision 48 extends DRAW-001/color fixtures: use explicit sRGB artwork semantics and the
reviewed native-picker-to-document conversion, with color-managed Skia/display presentation.
Changing system theme or display presentation must not rewrite stored colors. Verify conversion
and surface settings separately from real-display inspection; record untested display gaps.
Other color spaces remain future candidates, not scope for this implementation.

Decision 50 extends DRAW-001: during an active stroke, style controls/actions are disabled and
shared Rust rejects style commands without changing settings/artwork/history or queuing changes.
Cover shortcuts and already-open color-panel callbacks as well as direct command rejection.
Pressure variation continues normally. End/cancel restores availability subject to other guards;
a later stroke cannot receive a rejected queued change. Verify no auto-cancel/split or extra Undo.
Native control/focus tests require actual UI E2E; injected boundary cases remain separate.

Decision 58 extends DRAW-001/control integration: two drawings retain distinct current pen
color/width locally; restore accepted values on switching/reopening and apply them to new strokes.
Existing artwork/Undo/recency remain unchanged. Test shared validation and decision 50 rejection;
full restart/persistence cases integrate with S06. Native controls must reflect restored state
without bypassing focus/IME behavior. Do not infer a selected-tool restoration policy.

Decision 59: implement approved pen settings as the first typed tool-settings case under S02,
not as a universal hardcoded color/width API. Preserve per-drawing/device preference ownership,
shared validation and the active-stroke guard. Do not implement additional tools or preferences
from extensibility examples. Native controls remain specific to approved tool behavior.

Decision 73 extends DRAW-CANCEL-001/FOCUS-001: drawing-window deactivation cancels the active
stroke, removes actual/predicted preview and adds no stroke/history/autosave work. Prior completed
strokes/history remain. Test repeated cancel, late update/up, focus return and a fresh next stroke.
Native deactivation E2E is distinct from injected cancel tests and needs a reserved desktop.
Use the shared all-tool cancellation contract rather than a pen-only workaround.

Decision 76 extends DRAW-CANCEL-001: Escape during a stroke removes unfinished preview without
history/persistence; current tool stays selected. Continuing held input or late up cannot revive
it; a fresh interaction works. Verify repeated Escape and native field/IME/dialog priority through
shared fixtures plus actual native keyboard/focus E2E. Do not add a separate pen-only cancel path.

Decision 77 extends DRAW-001/NAV-001: during a stroke attempt canvas pan/zoom through implemented
native origins; verify fixed viewport, uninterrupted edit and no queued navigation jump on end/
cancel. Normal navigation afterward requires an eligible request. Shared fixtures cover ordering/
momentum, native tests cover actual scroll/pinch/keyboard events. No simultaneous-navigation feature.

Decision 78 adds DRAW-CANCEL-001/NAV-001 resize/display cases: cancel an unfinished stroke before
accepting changed canvas mapping; discard preview without history or partial save. Test repeated
notifications, stale update/up and fresh next stroke, preserving earlier content/save results.
Shared fixtures do not replace real native resize/backing-scale/display evidence; report missing
hardware. Use shared cancellation, not a pen-specific rollback.

Decision 79 requires one logical unit per AppKit point at 100% zoom, with backing scale applied
only for physical raster pixels. Test input/render agreement, zoom, transformed brush widths and
backing-scale changes without rewriting document geometry. Keep PNG resolution independent.

Decisions 88/93: initial stroke bounds are computed and cached only in bounded memory; verify
cold/warm/evicted equivalence. Initial preview displays actual input only, with no native/custom
prediction overlay. Retain future prediction separation contracts, but label prediction execution
coverage deferred. Verify actual coalesced input/order/cancellation and measure the actual-only
baseline without claiming physical latency from software timing.

Decisions 104/105/106: test whole-batch rejection and shared rollback for malformed current actual
samples, preserving prior completed work; stale identities cannot cancel a new gesture. Require
fresh begin after cancellation. Valid normalized pressure maps linearly from 0.10*W to W; absent
pressure uses W. Confirm hover/contact rules separately and validate actual Cintiq feel. Preserve
canonical floating-point sRGB values through typed commands/rendering; no implicit stored 8-bit
quantization. Concrete numeric representation/alpha/conversion contract still needs review.
