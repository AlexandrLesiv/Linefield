P11 Android XR

Status: planned; documentation/folder authorized, implementation not started.

Host: apps/android-xr. Owner: android_ui; ui_ux_designer owns interactions and native visual design per docs/design/roles.md.

Outcome: Initially a 2D drawing/viewing surface adapted from the Android host. Review editor/viewer capabilities and headset input before implementation. Immersive authoring, spatial tools and new gestures are not authorized by adding this folder.

Dependencies: macOS S08 acceptance, relevant reviewed Android adapter foundation, explicit implementation direction, approved platform scope and identified design states. Early feasibility/design planning is allowed now.

Before implementation: specify native toolkit compatibility, capabilities, typed boundary, thread/surface/resource ownership, lifecycle/storage, device/input support and acceptance IDs. Reuse Android/Rust semantics without duplicating state owners or adding command packets.

Evidence: actual target build/device or supported emulator checks, shared conformance/scenarios, native focus/input/navigation/accessibility, offline/loading failures, bounded rendering/logging/memory and accurate support limitations. For TV, include VIEWER-001; for XR, include approved editor or viewer scenarios and controller/hand/focus/resize checks applicable to the declared device.

Read [platform plan](../docs/platforms.md), [design foundations](../docs/design/foundations.md), [shared E2E](../docs/testing/shared-e2e.md) and [quality](../docs/quality.md). Select/verify exact supported SDK and test tools before coding. Missing hardware is not a pass. No system permission changes, desktop use, publishing or new features implied.

Internationalization: map CT-09/INV-11/SU-20 to native resource/formatting/input APIs and applicable locale scenarios; preserve shared semantics and read-only capabilities. Require English (en) and Ukrainian (uk), selected from OS/per-app preferences at launch (browser preferences on web), with no in-app switch. Require both locale E2E lanes and reviewed translations; no automatic support claim. See ../docs/internationalization.md.

Before host implementation, review [navigation](../docs/navigation.md) and [motion](../docs/design/motion.md).
Specify native Back/focus/restoration, URL/link entry if approved, interruption/reduced motion
and capability-specific cases. Map [shared route/motion tests](../docs/testing/navigation-motion.md)
to actual host execution; a generic replay or static mockup does not certify this host.

Launch acceptance includes I18N-LAUNCH-002/I18N-UK-002 on this host, including viewer UI where applicable. See docs/testing/internationalization.md; no resources or execution evidence exist yet.
