S00F Input inventory and feature-design integration

Status: inventory documented; per-feature behavior and identified design approval remain pending.
Owner explicitly deferred up-front binding decisions (decision 151). Read [input inventory](../docs/input/inventory.md).
No new keyboard, stylus, touch or OS-action mapping is selected by this task.

ui_ux_designer owns applicable-input coverage for each feature, including native app menus/Services/system actions.
Platform engineers verify native capabilities and conventions; rust_engine verifies shared command
semantics; UI designs discoverability/adaptive/focus/motion presentation in identified design; build
reliability maps acceptance to evidence. Lead assigns Linux/web/Apple-viewer feasibility explicitly.

For each feature: inventory applicable and inapplicable inputs with reasons, propose behavior/context,
conflicts/native text/IME priority, availability, interruption/cancel, simultaneous devices, accessible
alternatives and hardware gaps. Include native-only effects versus shared commands and CT/INV/SU/test
IDs. Preserve selected semantics; call out proposed changes rather than silently replacing them.

Submit this interaction plan with the feature design/design review for owner review BEFORE implementation.
Do not require a global shortcut or pen-mapping questionnaire before feature design can begin.
Use [historical matrix](../docs/input/platform-matrix.md) as research, not binding requirements.

watchOS, tvOS, Wear OS and Android TV/Google TV are view-only (decision 152). Plan only viewing,
browsing/navigation and applicable OS actions; shared capability tests must reject content mutation.
This does not approve new viewer features, toolkit/network choices or implementation.

After implementation authorization, feature owners add shared semantic and actual native E2E cases,
with real device evidence where needed. Replay is not physical pen/native coverage. Unknown capability,
missing hardware or inaccessible authoring remains a gap, not a pass. No tests/design review/code implemented.

[Historical research review](../quality/input-distribution-review.md) records earlier snapshots; the
new owner-directed inventory/workflow supersedes its pending consolidated-binding approval agenda.
