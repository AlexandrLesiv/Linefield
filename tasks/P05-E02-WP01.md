## Technical responsibility and acceptance

Rust remains the sole editor owner: stroke geometry, ordered actual input, settings/history,
interaction admission/cancellation, viewport transforms and frame compatibility. The host
acquires events and schedules bounded immutable geometry transfers. One worker owns CanvasKit;
the main host composites returned bitmaps and presents existing localized UI. No TypeScript
editing or visibility policy is introduced. Existing typed queries remain authoritative.

Preserve CT/INV/SU obligations of P05-E02, especially INV-01 sole ownership and stale-result
rejection, INV-02 ordered input, INV-03 atomic rejection and INV-04 cancellation/history.
Manual preview scenarios: draw real strokes; pan while rendering; cancel an active stroke;
finish A and immediately begin/cancel B while A is still rendering; preserve completed A.
Pan transforms must keep all presented ink aligned and exact-frame adoption must not jump.

The mandatory completed base cannot be coalesced away by newer preview requests. Keep one
job plus latest request marker, bounded page transfer and explicit bitmap disposal. Preserve
Rust content on renderer failure and retain the existing explicit recovery presentation.
Worker isolation is same-origin, with no network service, shared memory or new privilege.
Material deviations from the approved topology/ownership require renewed owner review.
