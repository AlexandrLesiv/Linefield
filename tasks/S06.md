# S06 Files and recovery

Status: planned; not implemented. 

Outcome: Implement revision-safe native file workflows and bounded recovery under approved schema/policy.

Dependencies: S03 through S05.

Responsible roles: rust_engine and macos_ui; build_reliability fault runner.

Acceptance IDs: SU-09, SU-10, SU-11, SU-12. See ../docs/successor/delivery.md for observable cases.

Required evidence: Native save/open/dirty guards/recovery tests, interrupted writes and revision races.

Before assigning writers, lead records exact base commit, owned paths, contract owner, dependency direction, applicable failure/privacy tests and stopping condition. Use isolated worktrees for concurrent writers. Implementers add structured diagnostics and tests alongside behavior. Do not claim independent review until a fresh reviewer actually ran.

Stop if a material ABI/schema/thread/security choice or new UI lacks owner approval. Keep missing device/permission evidence visible and continue independent authorized work. No main merge or release publication.
