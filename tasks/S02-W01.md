  state; CanvasKit is selected. No TypeScript editor, custom command packet or new storage.

## Concrete recommendations to finish and submit

1. Named generated Wasm bindings, exact integer identities/regions, bounded input copies
   and revision-tagged output copies. No exported raw pointers or long-lived mutable Wasm
   views. Present exact signatures, generator/version, errors, release and stale-call rules.
2. One page-main-thread Rust mutation owner and one active client for this slice. CanvasKit
   presents bounded Rust-derived geometry; TypeScript never computes document geometry.
   Explain future adapter portability without implementing workers, IPC or multi-client editing.
3. Recommend regional V4-B nearest-even normalization before admission, checked mathematical
   domain and checked carry; reject upper-region overflow rather than clamp. Supply exact
   rounding boundaries and an evidence-backed finite input/paint envelope. No guessed span,
   global Number flattening, or claim that historical point probes certify painted geometry.
   Pan/zoom controls and move/scale are excluded; retain Rust mapping and resize generations.
4. Specify round caps/joins, duplicate points/taps, pressure interpolation and bounded vector
   geometry, clipping and f32 conversion. Fix original scale/zoom at 1 for this slice if approved;
   this does not change the selected future transform ranges or imply a page boundary.
5. Reconcile sample/history/geometry/surface reservations within selected web caps. Specify
   before-allocation rejection, failed-batch cancellation, renderer startup/context-loss behavior,
   explicit disposal and fail-closed Wasm failure. Pin/audit locally served dependencies;
   review actual Wasm asset/CSP needs without adding network or broad security exceptions.
6. Propose making only the existing New preview editable. Existing raster sample cards remain
   demonstration previews, not imported editable documents. Retain the one temporary drawing
   in Rust RAM across Back/New; end its history session on successful departure. Reload/tab
   close loses it. No gallery record, thumbnail production, autosave or storage capability.
   Owner must confirm this lifecycle; an unsaved label alone does not decide retention.
   Designer's smaller alternative: New always starts blank, with Stay/Leave without saving
   confirmation before abandoning completed work. The lead recommends RAM retention to
   avoid routine Back navigation destroying work, but New's resume wording must be reviewed.
   No temporary gallery tile is proposed. Neither alternative is selected by this brief.
7. Keep the selected slim rail/top settings layout. Identify states for real width/color,
   Undo/Redo, unavailable prototype tools/opacity/smoothing, not-saved notice, initialization,
   failure, capacity, focus and reduced motion. Provide English/Ukrainian copy and responsive
   states. Preserve existing gallery routes, browser history, field/IME and theme behavior.

These are recommendations, not approvals. Exact packet version and conditions must be recorded
before P05-E01. Do not ask the owner to reapprove SQLite, regional representation or pen policy.
