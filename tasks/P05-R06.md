horizontal/vertical edges and15°/45°/90° Rust rotations. Only the historically measured small

Freeze named finite corpus before execution: coincident discs, thin strokes, pressure transitions,
retracing/self-crossings, fractional phases, approved rotations, edges/corners and outer viewport,
at1024×768 and4096×2048. No tolerance changes or excluded edge pixels.

(128+2h)² RGBA scratch, clear white, translate unchanged exported f32 path by(-(x-h),-(y-h)),
apply hard non-AA clip to original global viewport, draw full compound path once, byte-copy
central128px interior. No overlap blending, filtering, contributor culling or rewritten coordinates.
Compare exact CPU tile/whole and actual submitted bitmap; report CPU/GPU differences separately.
Optional padded-whole control is diagnostic only and cannot replace the oracle; restrict it
to small viewport to avoid exceeding existing8M-pixel surface bounds.

Reject each halo on its first correctness failure and advance to next approved candidate.
Freeze the smallest halo passing the entire corpus at both sizes. If none passes, or zero
control does not reproduce, return results without performance. Passing sampled cases is not
a universal proof. Integer Canvas translation may still round; exact checks remain necessary.

Gate2 begins automatically only after Gate1 passes. Keep selected halo fixed. Test concentrated
65,537 samples early, then retraced and sparse long strokes, cold/warm/evicted paths and complete

Retain4ms unit target/8ms guard and approved performance-profile deadlines. Count geometry

## Result and remaining boundary

Gate 1 rejected all four approved halos on clean source
`d61863f50f6d1d080b9efeeb4de61bf5a9de150a`. The original 256-sample control differs
at 24 pixels with zero padding; adding the explicit viewport clip alone changes nothing.
Padding 1/2/4 still differs at three pixels each. Padding 8 fixes that control and five
following small cases, then fails the thin diagonal at 192 pixels (maximum channel delta
48/255). Of those pixels, 159 are farther than 8px from a tile boundary. This is not
evidence of a remaining narrow seam or proof that a larger halo will solve it.

Four zero-control rows and ten padded candidate rows ran. Fail-fast rejection means the
remaining cases, including padded large-view cases, were not executed. CPU reference
repeatability and actual submitted-bitmap parity were exact for all executed rows.
Gate 2 was not run or implemented: large-stroke performance remains unmeasured.
