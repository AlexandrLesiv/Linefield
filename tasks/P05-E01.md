## Outcome and bounded implementation

Load real shared Rust compiled to Wasm and pinned CanvasKit in the existing New drawing
screen. Display an empty, fixed-light, in-memory Rust-owned canvas with approved loading,
not-saved and failure states. Back/Resume retains the same empty owner; loading, resize,
surface loss and disposal remain generation-safe. This foundation is not the usable pen;
[P05-E02](P05-E02.md) adds drawing and viewport interaction after separate confirmation.

Implement only these ten named exports from the approved contract:
`memoryCreate`, `memoryEnter`, `memoryRead`, `memoryMapping`, `memoryMetrics`,
`memorySuspend`, `memoryPresented`, `memoryLeave`, `memorySceneIds`, `memoryDispose`.
Generate Reply/State/Mapping/SceneIds snapshots with checked inputs, owned copied outputs,
bounded lifetime and explicit release. Empty SceneIds returns done=true; no stroke pages.
One page-main-thread Rust mutation owner controls lifecycle, metrics, identity exhaustion,
attachment/mapping/presentation generations and current-frame acknowledgement. Browser code
acquires metrics and presents state; it does not implement an alternative document model.

Include reproducible Rust/Wasm/Vite asset integration, identical pinned wasm-bindgen crate/CLI
0.2.129 and stock canvaskit-wasm0.41.1, local assets, actual generated-glue inspection,
release asset/security validation and minimal bounded privacy-safe diagnostics. Implement
approved R1 empty-frame surface/staging/snapshot ownership and recovery through the same
resource adapter used by later drawing. No unused commands returning pretend success.

Do not implement settings mutation, pen intake, stroke/history semantics, pan/zoom commands,
production N1 arithmetic or stroke geometry. Those belong E02. Keep unimplemented controls
honest; this task's result must not be presented as a working drawing tool. Preserve the
gallery/sample previews, navigation, focus/IME, themes, English/Ukrainian and reduced motion.
Exclude persistence, native applications, import/export, extra tools, selection, cloud,
workers/IPC, sample-image conversion and new product behavior beyond this foundation.
