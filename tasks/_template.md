# Short task title

**Task:** ID · **Status:** proposed / in progress / awaiting owner review / blocked / done
**PR:** link when created · **Depends on:** task IDs, or none

## What changes

Describe the user-visible outcome in a few sentences. State the approval needed, if any.

## Scope

List the work included and the important exclusions. Link shared requirements instead of copying
general agent instructions or repeating the architecture specification.

## Acceptance

List observable outcomes with stable acceptance IDs. Link the primary-app test source and scenario
selectors in task.json; planned tests must remain clearly planned.

## Related material

Link the current architecture definitions, approved design sources and relevant implementation.
Attach necessary screenshots and run results to the PR rather than committing report copies.

## Review

State outstanding decisions or findings. Distinguish agent review from owner acceptance.
Completion requires the owner's merge/acceptance and applicable integration verification.
