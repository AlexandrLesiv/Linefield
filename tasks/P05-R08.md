## Approved mechanism

Preserve canonical samples, pressure/radii, history, editing admission/cancel and regional
projection. Keep CanvasKit0.41.1 CPU, current f32 conics/quads, antialiased nonzero fill once per
whole stroke and exact CPU pixel acceptance. Rust removes only whole projected contours proved
redundant: exact byte identity or full-area containment through conservative inner/outer polygon
certificates. No old-contour retirement, reconstructed curves, PathOps, tiles/padding, shader,
sampling/smoothing, sample/stroke quota, separate TypeScript engine or renderer switch.

Certify nonnegative winding of the complete captured prefix. Inconclusive containment keeps
the contour. Uncertifiable winding invalidates all earlier omissions, disables compaction for
that stroke/mapping epoch and reconstructs the original prefix before publication.
Different candidate area pieces may have different coverers, but each whole piece must be
inside one retained convex inner polygon. Covering only a boundary or a convex hull spanning
separate shapes is insufficient. Earlier retained witness contours remain retained.

One new pure-derived Rust/Wasm instance runs inside the existing single render-worker topology,
beside one CanvasKit instance. No Engine/document APIs are linked into the preparation module.
No second editor, full document replica, shared memory, storage, networking or privilege change.
Use generated typed Create/BeginNextPrefix/Feed/Step/Drain/Release operations; keep source and
output cursors distinct. Compatible continuation reads only the newly appended source suffix.

Add opaque revocable active/current-visible/target-bound prefix captures in the sole editor.
Freeze source sample count/verb end, color, bounds, view/metrics and a validated ID/index locator.
One capture is held for the currently serialized stroke; no pointers or copied document.
Append preserves its finite prefix; End moves its locator. Current-visible capture works after
End while B is active and for idle history rebuild without a pan target. Cancelling unrelated B
cannot invalidate compatible committed A. Revocation is permanent across Undo/Redo.
Target-bound captures preserve the existing continuous-pan compatibility and adoption checks;
mapping changes on every pan move must not restart them. Incompatible content/surface/view changes
revoke according to that target contract. Exact source validity alone never authorizes display.

## Frozen numerical, work and resource profile

Only current closed disc/quad templates and exact binary32 FRAC_1_SQRT_2 weights are supported.
Exact homogeneous dyadics at2^-189, subdivision depth≤8, rotation-inclusive2^22 envelope and
checked signed12×64-bit magnitude workspace require independent Gate0 proof before kernel code.
No heap big-integer dependency, epsilon containment or floating-point reconstruction of proof signs.

Per contour:≤16 cover candidates,≤256 exact predicates,≤256 spatial nodes and≤16 full-byte
collision comparisons. Per step:≤16 predicates or one bounded lookup/emission; validation≤32
contours/4KiB; maintenance/disposal≤32 entries. Incomplete lookup/proof retains original geometry.
Measure all indivisible operations; fixed counts do not establish timing success.

Optional indexes, original encodings used for collision checks, polygons and capacity overhead
share16MiB per worker. Eviction reduces optimization, never artwork/history. Original source is
requeried through its valid finite capture on fallback, not retained as another full stream.
Transport≤two buffers/512KiB; Rust input/output scratch≤256KiB each; fixed predicate workspace.
Count live builders/paths/snapshots, linear-heap capacity and backing separately. One replacement
can coexist with its prior valid path; one replacement builds at a time.
320MiB CPU/96MiB graphics remain soft targets; excess alone never rejects a stroke.
Actual allocation/worker/surface failure preserves accepted state and coherent display where
possible, cleans incomplete resources and uses existing localized failure/retry behavior.
