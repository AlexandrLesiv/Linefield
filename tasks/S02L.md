## Scope and design handoff

- Empty and populated gallery, New, open an existing library item, rename and deletion flow.
- Thumbnail/card representation, keyboard navigation, accessible names, native text editing,
  English and Ukrainian resources and pseudo-expanded/RTL states. Synthetic previews during gallery-only
  checks must be identified as fixtures, not evidence of rendering actual drawings.
- New creates a durable library document without a filename/location prompt. An unnamed item
  is saved user content, not an expiring draft. Normal close/return retains it.
- Loading/unavailable/creation-write failures, cancellation, retry and focus restoration.
- Gallery-to-editor and back motion, interrupted/reduced-motion behavior; resolved identity
  and guarded navigation before changing visible destination.

Before S04, verify open/create destinations through an explicitly designed temporary non-drawing
host state; label this gallery-only evidence. Replace that state in S04. It is not a functioning
canvas or a pass for drawing, thumbnails of actual artwork or ink autosave.

Do not copy all Procreate features: stacks/folders, search, multi-select/bulk operations,
cloud sync, time-lapse and extra export formats are deferred. Current deletion direction is decision 212: recoverable removal with in-place Undo until successful departure; no general Recently Deleted screen or system Trash is implied. Concrete durable staging/finalization needs review.
External native files use independent import copies (decision 9), implemented in S06; no automatic
source write-through. Launch always enters the gallery, including after crash recovery (decision 19); no last-editor
restoration or Continue action. Most recently edited first is selected (decision 20), without sorting controls.
Decision140 selects a library-wide Untitled sequence; retain unnamed items until explicitly deleted.
Web leads implementation; macOS is the next native host, followed by iPhone/iPad (decision231).

## Contracts, acceptance and evidence

CT-01/03/05/07/08/09 and INV-06/07/11 apply; freeze concrete mapping in S02. Commands from native
controls/shortcuts use shared Rust semantics; presentation stays native. Catalog metadata and
thumbnail caches are separate from each document's SQLite content. Decision 22 selects a separate SQLite catalog plus one SQLite file per drawing. Metadata authority,
connection ownership and cross-file consistency remain for review. Propose
crash-consistent ordering and reconciliation; do not assume separate files commit atomically.
Thumbnail jobs later use bounded queues and revision checks, never block ink or falsify content.

SU-21 is the new library acceptance requirement. Required shared scenarios:
- LIBRARY-CREATE-001: create without naming, verify identity/item, restart and reopen.
- LIBRARY-RENAME-001: rename using native field; Unicode and text shortcuts preserve identity.
- LIBRARY-OPEN-001: open existing item; failure/cancel retains prior valid route/content.
- LIBRARY-DELETE-001 (decision 212 supersedes prior confirmation/no-Undo row): recoverable removal, same-slot Undo per item, failed/cancelled navigation retention, restoration and reviewed finalization/restart outcomes.
  Test pending-write races, stale thumbnail/save completions and failure/interruption; no ghost
  item recreation or false success. Concrete crash-consistency policy requires S02 review.
- LIBRARY-FAILURE-001: storage/list/create failure is visible; no phantom durable item or lost item.
- LIBRARY-NAV-001: keyboard/AX focus, gallery/editor back flow, reduced motion and cancellation.

Core/boundary tests and real macOS E2E are separate lanes. Record exact revision/device/test IDs
and artifacts. Use disposable fixtures; ask before reserving desktop focus. Exercise rename/create
persistence and abrupt restart in this milestone; full stroke-content recovery follows S04/S06.
Log bounded redacted operation outcomes, not names/paths/thumbnails. Missing tests are not passes.

Completion: owner-approved design review/schema/contracts, working gallery slice, applicable automated
checks/native E2E, UX/UI review and fresh independent assessment. No main merge or publication.

## Decision 212 supersedes ordinary delete confirmation

The gallery design uses same-size Deleted NAME / Undo placeholders until successful navigation
away. This is distinct from document edit Undo. Before runtime work, propose the durable staging,
crash/restart/quit recovery, restoration/finalization failure and concurrent-owner contract for
review; do not reuse decision 85's irreversible intent at the first tap. Keep busy-item rejection
and explicit export-cancellation consent. Prototype evidence cannot certify real deletion safety.
