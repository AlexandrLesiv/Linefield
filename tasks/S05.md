## Selected interaction policy

Follow decision 17/R05: explicit Select mode, nearest eligible stroke with topmost tie-break,
drag move, opposite-corner uniform scaling including width without flipping, Space-drag/scroll
pan, gesture-anchored pinch and center-anchored menu zoom. Escape cancels an active transform,
otherwise clears selection; focus loss cancels unfinished transforms. Native field editing wins.

Extend EDIT-MOVE-001, EDIT-SCALE-001, NAV-001 and FOCUS-001 with overlap ties, zoom-independent
hit tolerance, fixed scaling anchor/width, zero-crossing prevention, cancellation and one Undo
per completed gesture. Cancelled/no-op transforms add none. Prove Pen-mode crossings do not
select existing strokes. Use reviewed CT-02 tolerances/limits and design review handle specifications;
no extra tools or implementation authorization is implied by this recorded choice.

Decision 25: preserve original samples when moving/scaling; update the current per-stroke
translation/positive uniform scale. Extend EDIT-MOVE-001/EDIT-SCALE-001 and core tests with
unchanged sample rows, scaled width, composed transformations, anchor/cancel/Undo correctness
and transformed hit/culling bounds. Persistence round-trip follows S06 and PNG parity follows
S07E; do not claim those later integrations passed from S05-only evidence.

Decision 39: extend history tests for oldest-whole-operation retirement within reviewed memory
limits. Assert current artwork/revision/save state does not change, retained Undo/Redo remains
valid, single-stroke/transform operations stay atomic and deleted geometry is released only when
unreferenced. Cover history cursor/branch changes, structural sharing and oversized-operation
admission/cancel. Update native command availability via shared projections; add no history UI.

Decision 73 applies the same shared focus-loss cancellation to unfinished move/scale and all
future tools: restore pre-interaction state, remove preview, add no Undo/partial save and retain
prior completed changes/history. Test repeat cancellation, stale update/end, restored focus and
new interaction through shared fixtures plus real native deactivation. Do not roll back unrelated
worker acknowledgements or allow tool-specific implicit commit-on-focus-loss behavior.

Decision 74 adds Undo/Redo acceptance during every implemented active tool interaction: commands
reject without affecting the gesture, prior content/history or scheduling deferred history work.
Verify disabled native actions and shortcut routing; end/cancel recomputes availability from
actual history. Include empty history, stale callbacks and a new explicit valid request. Native
text-field Undo/IME must retain platform behavior; injected checks do not substitute for UI E2E.

Decision 75 adds tool-switch guard scenarios for every implemented active interaction: attempt
switch through native controls/menu/shortcut and shared command, verify unchanged active tool,
settings/preview/history/local active-tool metadata and no queued action. End/cancel, then issue
a fresh switch and verify correct tool/settings. Cover stale events and native text-field routing;
real native E2E is separate from admission/race fixtures.

Decision 76 extends FOCUS-001/selection cases: Escape cancels an active move/scale via shared
rollback, otherwise clears selection, otherwise performs no canvas action. Current tool remains
selected. Verify repeat/stale events, unchanged prior history/content and first-responder native
Escape behavior; do not consume one event in both native composition/dialog and canvas handling.

Decision 77 extends NAV-001 during move/scale: reject pan/zoom without changing viewport/history
or committing/cancelling the transform. Verify no deferred movement, then normal navigation after
end/cancel. An idle selection does not disable pan/zoom; navigation's own gesture updates work.
Test actual native controls/events separately from shared command/race fixtures.

Decision 78 adds active move/scale resize/display cases: shared cancellation restores only the
unfinished transformation before changed canvas mapping is accepted. Preserve prior history,
selected tool and completed artwork; no queued actions or stale-event revival. Test repeat
notifications and fresh next interaction. Separate injected ordering from actual native resize/
display E2E and record hardware gaps. Future tools inherit common interruption semantics.

Decisions 107/108: Select measures screen-space distance to full visible stroke geometry, with
zero for interior hits, existing tolerance and topmost tie-break. Test wide/narrow/pressure strokes,
transforms, overlap, zoom and display scale; handle precedence remains reviewed. Moving/scaling
preserves drawing order in commit/cancel/no-op/Undo/Redo, persistence and export. No automatic
bring-to-front, reordering controls or extra history operation.
