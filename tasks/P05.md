## SQLite portability checkpoint

Decision 29 selects native rusqlite; its documented sqlite-wasm-rs backend is a browser candidate,
not an accepted runtime. Before full web UI work, verify a reviewed worker/VFS arrangement with
create/edit/save/reload, native/browser snapshot exchange, migrations, quota exhaustion,
competing-tab locks, unavailable/private storage and interrupted saves. Default memory-only
storage must never be presented as persistent. Keep command/state/save policy shared in Rust;
report browser-specific durability/capabilities honestly. Browser journal mode and worker
ownership require review; macOS WAL/disk synchronization cannot be assumed to carry over.
These are planned checks, not implemented or executed evidence.
