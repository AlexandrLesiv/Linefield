fill once per complete stroke, full-viewport clipping/conversion and one isolated worker.
Reuse complete terminal paths and append only new complete-contour pages to a valid active
builder. Snapshot/draw of the complete active path still counts; no incremental-raster claim.
No stable bitmap cache, tile/padding, PathOps, coverage masks, custom shader, simplification,
sample removal/limits, dependency, new ABI, shared memory, second editor or production migration.

Geometry token currently equals mapping generation. End of another stroke or Undo/Redo
changes scene membership while unchanged mapping/stroke geometry can be reused. An undone
path may remain cached but must not be drawn until Rust exposes it. A new accepted End
truncates redo; new stroke IDs cannot alias the removed operand. Every frame reenumerates
current membership/order and validates stroke state. Do not infer world-space geometry in JS.

## Resource and security contract

One worker/CanvasKit heap; one in-flight publication and one latest pending target. Cold:
initialized renderer without paths/images. Warm: same mapping paths prepared, including one
undone Redo operand. Evicted: explicitly delete disposable paths/images and verify release
before rebuilding unchanged Rust state. Reclamation during warm work is a separately labelled
transition. Clear between workload rows. At most1,025 terminal paths, one active builder and
one transient active snapshot: fixture inventory bounds, not product stroke/history limits.

Measure commands/queries/copies, path preparation, allocations/snapshot/COW, clear/full raster,
conversion/readback, bitmap transfer/submission/ack, event delay, queue wait, worker busy time
and superseded targets. Count actual geometry sizes/heap capacity/handles; no invented path bytes.
RGBA backing costs3MiB small/32MiB large. Large worker surface+readback≈64MiB; prior/new
bitmaps+display≈96MiB additional before paths/driver. Separate comparison-only memory.
320MiB ownedCPU/96MiB graphics stay soft targets; excess never discards accepted work.

Classification: existing sensitive geometry/worker boundary exercised, no production authority
change. Only fixed synthetic fixtures enter the existing typed API; copied arrays are worker-owned.
No network/storage/user drawing capture, privilege, schema or dependency changes. Bounded
metadata diagnostics and ignored local images only. Allocation/conversion/worker failure
preserves Rust state, stops candidate and reports stage; timeout terminates only fixture worker.
