## Frozen experiment and technical responsibility

Test the pinned CanvasKit0.41.1 CPU rasterizer against the existing GPU renderer, using
unchanged f32 Rust conics/compound contours, nonzero fill and AA enabled. No PathOps,
supersampled masks, sample reduction, shader, dependency or production renderer migration.
Prefer MakeSurface (sRGB/RGBA8888/Unpremul); explicitly account for GPU Premul storage and
compare identically formatted readback/composition. Never transfer live Wasm heap views.

| Area | Rust | Host / experiment |
| --- | --- | --- |
| Editing/history | Sole mutable owner; input/settings/End/Cancel and Undo remain unchanged | Script accepted fixture input; never invent drawing geometry |
| Geometry/view | Existing authoritative projection, conics, identities and page validation | Copy finite frozen pages; preserve f32 values; integer tile translation only |
| Rendering | No new ABI or mutable worker editor | One worker owns CanvasKit surfaces/paths, extraction, bitmaps and disposal |
| Publication | Existing production validation remains unchanged | Isolated comparison canvases, bounded requests and labelled synthetic timings |
| Failure | Canonical work/production state untouched | Stop candidate, dispose/terminate resources, retain stage/result evidence |

Build one path per immutable prefix and reuse it across tile draws. Include construction
in cold and continued-prefix totals.128px tiles bound pixel storage, not contour traversal.
Measure full visible-frame work, extraction/copy/conversion, bitmap transfer/submission and
queued next-input work; raster-only duration is not input latency or GPU completion.

Two separate oracles: CPU tiled versus CPU whole rendering requires exact RGBA equality;
CPU versus GPU differences are reported separately and require owner review before adoption.
No automatic tolerance relaxation. Thin-artwork disappearance or tile seams reject the candidate.
Initialize/clear all buffers; surface/image/path ownership ends explicitly on success or failure.
