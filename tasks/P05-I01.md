## Outcome and scope

Let the user choose whether finger contact draws or remains available for browser gestures.
The first in-memory pen keeps fingers excluded from ink; mouse and pen draw. This follow-up
does not change that initial default. Define the setting's label, placement, default, lifetime
and application timing before implementation. Retain pen pressure and shared Rust edit guards.

Review mixed pen/touch events, browser gesture takeover, cancellation, stale events, focus,
accessibility and localized guidance. A preference change cannot silently commit unfinished ink.
Keep input acquisition in the browser and editing/admission policy in Rust. No palm-rejection
promise, new brush, app-owned pan/zoom, stylus-button mapping or native host is implied.
Persisting this preference requires an approved settings-storage contract; do not invent one.
